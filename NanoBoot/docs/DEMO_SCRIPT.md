# NanoBoot Live Demonstration Script

## Before the review

Open Ubuntu/WSL in the extracted project directory and run:

```bash
bash START_NANOBOOT.sh
```

The launcher rebuilds the kernel, runs static verification, executes the QEMU smoke test, and then launches an interactive QEMU console. After the smoke test, its console transcript is saved at `tests/qemu-output.txt`, and the build plus all PASS/FAIL checks are logged in `tests/verification-results.txt`.

## Commands to type at the live `nb$` prompt

Run these one at a time so the reviewer can see each result:

```text
help
getpid
ps
echo hello from NanoBoot
isotest
ls
cat README.txt
cat hello.txt
sleep 3
forktest
```

Expected demonstrations:

- `help`: lists commands available in the user shell.
- `getpid`: returns the current process ID through `ecall`.
- `ps`: prints the kernel's fixed process table.
- `isotest`: the kernel rejects a user request to read a supervisor-only kernel address.
- `ls` / `cat`: list/read the in-memory RAMFS files.
- `sleep 3`: blocks and wakes after timer ticks.
- `forktest`: shows parent/child process execution and parent wait completion.

Use `exit` only at the end. The QEMU process remains in the idle kernel afterwards; press `Ctrl+A`, then `X` to close the QEMU console.

## Evidence to show the reviewer

1. `tests/verification-results.txt` — build/static-test log with the runtime PASS/FAIL results.
2. `tests/qemu-output.txt` — transcript generated by the automated live smoke test.
3. `kernel.elf` and `kernel.bin` — compiled RISC-V kernel artifacts.
4. `user/sh.elf` and `user/sh.bin` — separately linked user-shell artifacts.
5. `kernel.disasm` — disassembly of the built kernel.
6. `user/sh.disasm` — disassembly of the user shell, including the `ecall` wrappers.
7. `docs/VERIFICATION_REPORT.md` — static-build results and an explicit live-test status.

Do not describe the live smoke test as passing unless `START_NANOBOOT.sh` reaches the interactive prompt after the automated checks print all `PASS` markers.
